# Política de privacidade do JARVIS Pessoal

Última atualização: 20 de outubro de 2026.

O JARVIS Pessoal é um assistente de inteligência artificial de uso exclusivamente pessoal do dono desta conta. Ele roda em um computador próprio do dono e não atende outras pessoas.

## Dados acessados

Com a autorização explícita do dono, o JARVIS acessa os eventos da Google Agenda dele (permissão calendar.events) para consultar, criar e remover compromissos quando o dono pede.

## Uso e armazenamento

Os dados da agenda são usados somente para responder ao dono e enviar lembretes a ele. Eles são processados no computador do dono. Os lembretes são enviados apenas ao próprio dono, pelo WhatsApp e pelo serviço de notificações ntfy. Os dados não são vendidos nem compartilhados com outras pessoas, e não são usados para publicidade nem para treinar modelos de inteligência artificial.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

## Revogação

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions
